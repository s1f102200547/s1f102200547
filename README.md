### 🔬 What I'm Working On

My graduation research tackles a real gap in enterprise integration:

> **How do you synchronize business data across SaaS tools that have no public API or webhook?**

I'm building an **AI agent framework** with three layers — **Perception → Operation → Normalization** — that reads, acts on, and structures data from web UIs through browser automation.
